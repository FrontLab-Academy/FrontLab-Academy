# Progressão da trilha de CSS

1. Fundamentos: conexão, cascata, especificidade, cores, tipografia e box model.
2. Layout: fluxo, posicionamento, Flexbox e Grid.
3. Componentes: estados, formulários, tokens e reutilização.
4. Responsividade: mobile-first, mídia fluida, breakpoints e container queries.
5. Qualidade: contraste, foco, redução de movimento e desempenho.
6. Projeto: interface responsiva com critérios visuais e auditoria.

Cada módulo deve combinar explicação curta, exemplo executável, prática incremental e exercício com resultado observável. A conclusão exige testar pelo menos três larguras e documentar uma decisão de layout.
