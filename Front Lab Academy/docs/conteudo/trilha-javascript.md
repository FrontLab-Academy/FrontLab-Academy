# Progressão da trilha de JavaScript

1. Sintaxe, valores, condicionais, loops e funções.
2. Arrays e objetos com transformação, busca e imutabilidade.
3. DOM, eventos, formulários e feedback de interface.
4. Assincronicidade, Fetch API e estados de loading, erro e vazio.
5. Persistência defensiva com `localStorage` e validação de dados.
6. Projeto: aplicação orientada a estado com API e testes de regras.

Cada módulo contém exemplo guiado, alteração proposta, prática verificável e critérios de conclusão. Exercícios devem cobrir caminho feliz, entrada inválida e estado vazio.
